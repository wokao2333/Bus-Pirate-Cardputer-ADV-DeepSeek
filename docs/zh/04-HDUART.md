# 半双工 UART 模式

半双工 UART 使用同一根数据线进行发送和接收，适合调试单线串口或一些共享总线设备。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `config` | 配置数据引脚、波特率和串口参数 |
| `read` | 从半双工总线读取数据 |
| `write <data>` | 向半双工总线写入数据 |
| `bridge` | 进入交互式桥接 |
| `help` | 查看命令 |

## 使用建议

- 半双工线路容易被多个设备同时驱动，测试前确认目标总线空闲。
- 如果设备需要上拉，请根据硬件情况开启或外接合适电阻。

## 示例

```bash
mode hduart
config
read
write hello
bridge
```
