# I2C 模式

I2C 模式通过 SDA/SCL 两根线和 I2C 设备通信，支持扫描、读写寄存器、嗅探、模拟从机、EEPROM 操作和总线恢复。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `scan` | 扫描 1 到 126 地址，列出有 ACK 的设备 |
| `ping <addr>` | 检查指定地址是否响应 |
| `discovery` | 执行更详细的 I2C 设备发现 |
| `identify <addr>` | 根据地址尝试识别常见设备 |
| `sniff` | 被动监听并解码 I2C 流量 |
| `read <addr> [reg]` | 读取设备寄存器 |
| `write <addr> [reg] [val]` | 写入设备寄存器 |
| `dump <addr> [len]` | 读取一段设备存储或寄存器内容 |
| `regs <addr> [len]` | 转储并测试寄存器读写情况 |
| `slave <addr>` | 模拟 I2C 从机并记录主机操作 |
| `glitch <addr>` | 注入异常信号测试设备稳定性 |
| `monitor <addr> [ms]` | 周期监控寄存器变化 |
| `trace <addr> [reg] [ms]` | 持续监控指定寄存器 |
| `eeprom [addr]` | 进入 I2C EEPROM shell |
| `recover` | 尝试释放被拉低的 I2C 总线 |
| `swap` | 交换 SDA 和 SCL 引脚 |
| `config` | 配置引脚和频率 |

## EEPROM 操作

`eeprom [addr]` 可用于常见 24XX / AT24C 系列 EEPROM，支持探测容量、读取字节、写入字节、完整转储和擦除。默认地址通常是 `0x50`。

## 示例

```bash
mode i2c
config
scan
identify 0x18
ping 0x3C
read 0x3C 0x00
write 0x3C 0x01 0xFF
dump 0x3C 128
monitor 0x13 1000
trace 0x63 0x10 200
eeprom
recover
swap
[0x3C 0x00 r:4]
```
