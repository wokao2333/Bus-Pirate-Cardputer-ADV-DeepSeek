# I2S 模式

I2S 模式用于音频输入输出测试，例如扬声器、麦克风和简单音频播放。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `config` | 配置 I2S 引脚和音频参数 |
| `speaker` | 测试扬声器输出 |
| `mic` | 测试麦克风输入 |
| `play` | 播放声音 |
| `record` | 录制或采集音频 |
| `help` | 查看命令 |

## 使用建议

- I2S 需要正确配置 BCLK、LRCLK、DIN/DOUT 等引脚。
- 若没有声音，检查采样率、声道、放大器使能和供电。

## 示例

```bash
mode i2s
config
speaker
mic
play
record
```
