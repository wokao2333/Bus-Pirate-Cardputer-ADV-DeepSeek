# RF24 模式

RF24 模式用于 nRF24L01 系列 2.4 GHz 无线模块，支持扫描、发送和接收。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `config` | 配置通道、地址、速率和引脚 |
| `scan` | 扫描 2.4 GHz 通道活动 |
| `send` | 发送数据包 |
| `receive` | 接收数据包 |
| `sniff` | 监听相关通信 |
| `help` | 查看命令 |

## 使用建议

- nRF24L01 对供电质量敏感，建议使用稳定 3.3V 电源并加去耦电容。
- 通道、地址宽度和速率需要和目标设备匹配。

## 示例

```bash
mode rf24
config
scan
receive
send
sniff
```
