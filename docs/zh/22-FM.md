# FM 模式

FM 模式用于 FM 频段分析和广播相关实验，具体功能取决于所连接的无线硬件。

## 常用命令

| 命令 | 说明 |
| --- | --- |
| `config` | 配置频率和无线参数 |
| `analyze` | 分析 FM 信号或频段 |
| `broadcast` | 进行广播测试 |
| `scan` | 扫描频率 |
| `help` | 查看命令 |

## 使用建议

- 广播发射受法律限制，请只在允许频率、功率和授权环境中测试。
- 使用合适天线，避免长时间无负载发射。

## 示例

```bash
mode fm
config
scan
analyze
broadcast
```
